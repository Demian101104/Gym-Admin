# Requisitos No Funcionales

## 1. Introducción

Los requisitos no funcionales establecen las características de calidad que deberá cumplir el Sistema de Administración y Control de Gimnasio (SACG), con el propósito de garantizar un funcionamiento adecuado, seguro y confiable.

## 2. Requisitos no funcionales

### RNF1. Rendimiento

El sistema deberá procesar las operaciones de consulta, registro y actualización de información sin presentar demoras innecesarias.

Las operaciones principales deberán responder de manera ágil para permitir que el administrador y el recepcionista realicen sus actividades sin interrupciones.

### RNF2. Seguridad

El sistema deberá proteger el acceso mediante autenticación de usuarios con credenciales propias.

Deberá identificar el rol de cada usuario y permitir únicamente el acceso a las funciones correspondientes a sus permisos.

### RNF3. Fiabilidad

El sistema deberá mantener la integridad y consistencia de la información relacionada con los usuarios, socios, membresías y pagos.

Asimismo, deberá evitar registros incompletos o inconsistentes y conservar correctamente la información después de cada operación.

### RNF4. Disponibilidad

El sistema deberá mantener disponible la información necesaria para que el administrador y el recepcionista puedan realizar sus actividades de acuerdo con sus respectivos permisos.

### RNF5. Mantenibilidad

El sistema deberá contar con una estructura organizada que permita realizar correcciones, actualizaciones y mejoras sin afectar innecesariamente las funciones existentes.

El código y los módulos deberán facilitar la identificación y corrección de errores.

### RNF6. Portabilidad

Por el momento no se establece un requisito específico de portabilidad. Este aspecto podrá definirse posteriormente de acuerdo con la plataforma y las tecnologías seleccionadas para su implementación.

## 3. Consideraciones finales

Los requisitos no funcionales buscan garantizar que el sistema de administración del gimnasio funcione correctamente, mantenga protegida la información y facilite las actividades cotidianas de los usuarios autorizados.
